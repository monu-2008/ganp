GANPATI: VIGHNA

A Game by AQX

This vertical slice is built with reverence for Lord Ganesha and the living tradition of Ganesh Chaturthi. The character of Mooshak (the divine mouse vāhana) appears as a tribute to the small, the clever, and the unseen.

All music and sound are synthesized at runtime via the Web Audio API — no commercial recordings are used. Geometry is generated procedurally by Blender Python scripts; no third-party 3D assets are shipped.

Lord Ganesha is worshipped as Vighnaharta — the remover of obstacles. This game is offered in that spirit.
